## 🛠️ Phase 1: CI/CDシンプル化（2-3日）

### 現状の問題
- 共有リポジトリ構造が複雑すぎる
- workflow_call方式が管理困難
- 3プロジェクト統一は時期尚早

### 解決策: プロジェクト単体へ回帰
```
選択肢A: シンボリックリンク修復（保守的）
- github-sharedリンクを正しく作成
- quick-check.shを機能させる
- 既存システムを維持

選択肢B: スクリプトのローカル化（推奨）
- 必要なスクリプトをdiffx内にコピー
- 共有リポジトリへの依存を削除
- シンプルで理解しやすいCI/CD

選択肢C: GitHub Actions標準化
- rust-actionなど標準的なactionを使用
- カスタムスクリプトを最小化
- メンテナンス負担を削減
```

### 推奨: 選択肢B（ローカル化）
理由:
- diffx単体で完結する
- lawkit/diffaiは後で考える
- デバッグしやすい
- シンプル

実装:
1. `.github/workflows/`を完全にdiffx固有にする
2. `scripts/`配下に必要なスクリプトをコピー
3. 共有リポジトリへの参照を削除
4. quick-check.shを作成・動作確認
