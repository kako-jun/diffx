## ⚙️ CLIオプション（検証済み）

### 基本オプション
- [x] **`--output json`** - ✅ 動作確認済み
- [x] **`--output yaml`** - ✅ 動作確認済み

### 実用的オプション
- [x] **`--quiet`** - ✅ 動作確認済み
  - 差分なし: exit 0, 出力なし
  - 差分あり: exit 1, 出力なし
  - スクリプトでの利用に最適

### フィルタリングオプション
- [x] **`--ignore-keys-regex`** - ✅ 動作確認済み
  - 正規表現でキーを無視
  - 例: `"^timestamp$|^_.*"` でtimestampと_始まりのキーを無視
  - 完全に動作

- [x] **`--epsilon`** - ✅ 動作確認済み
  - 数値比較の誤差許容
  - 例: `--epsilon 0.01` で0.01以内の差を無視
  - 完全に動作

- [x] **`--array-id-key`** - ✅ 動作確認済み
  - 配列要素の識別キー指定
  - 例: `--array-id-key id` でIDフィールドで配列要素を追跡
  - 出力が `users[0]` から `users[id=1]` に変わる
  - 完全に動作

### 部分的動作・要検証のオプション
- [⚠️] **`--ignore-case`** - ⚠️ 部分的動作
  - 値の比較では動作している様子
  - キー名の比較では動作していない可能性
  - README_ja.mdの説明が不明確（値のみ対象？キーも対象？）
  - 詳細な検証が必要
